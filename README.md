# Fusehand samples

Reusable examples for Oracle Fusion Cloud technical work, published by
[Fusehand](https://fusehand.com), an Oracle Fusion SaaS and PaaS technical team.

Every sample uses standard Oracle Fusion objects and test data only.
There is no client code or client data in this repository.

| Folder | What's inside |
|---|---|
| [`bip/`](bip) | BI Publisher SQL data model queries (Oracle join syntax) |
| [`hdl/`](hdl) | HCM Data Loader sample files and load notes |
| [`fbdi/`](fbdi) | File-Based Data Import checklist |
| [`oic/`](oic) | Oracle Integration (OIC) design patterns |
| [`agents/`](agents) | Oracle AI Agent Studio use-case designs |
| [`extracts/`](extracts) | HCM Extract design checklist |
| [`vbcs/`](vbcs) | Visual Builder notes |

## Using these samples

- Always test in a non-production environment first.
- Table and column names can change between quarterly updates. Check them against
  the *Tables and Views* guide for your release before using a query in production.
- Parameters are written as BI Publisher bind variables, for example `:p_as_of_date`.
